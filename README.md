# PPVT 그림어휘력 검사

취학 전 아동을 위한 로컬 그림어휘력 검사 앱입니다.

## 구성
- 총 20문항, 4개 범주(동물, 음식, 일상용품, 몸과 행동)별 5문항
- 문항마다 정답 1개와 오답 3개
- 로컬 pic 폴더의 SVG 그림 사용
- 그림 파일이 없으면 그림 대신 단어 카드가 표시되며, 카드 아래에 필요한 그림파일명이 표시됨
- 문항별 반응 시간, 총점수, 범주별 점수, 평균 반응 시간 기록
- 브라우저 localStorage에 검사 기록 저장
- CSV 내보내기

## 실행
정적 파일 서버로 프로젝트 폴더를 연 뒤 index.html을 열어 사용합니다. 예: VS Code Live Server 등.

## 검사 안내
검사자가 문항의 낱말을 읽어 주고, 아동이 네 그림 중 하나를 선택합니다. 현재 화면은 개발/시범용으로 선택지 낱말도 함께 표시합니다.
